
# Interactive Dashboard Development

## Project Overview
This project develops an interactive sales dashboard using Python and Streamlit. It helps users analyze sales, profit, and regional performance through interactive charts and visualizations.

## Technologies Used
- Python
- Pandas
- Plotly
- Streamlit

## Features
- Total Sales Analysis
- Total Profit Analysis
- Average Sales Calculation
- Monthly Sales Visualization
- Profit Analysis
- Region-wise Filtering
- Interactive Data Table

## Project Files
- app.py - Main interactive dashboard application
- dashboard.py - Data analysis and visualization
- requirements.txt - Required Python libraries

## How to Run

1. Install Python.
2. Install the required libraries:

   pip install -r requirements.txt

3. Run the application:

   streamlit run app.py

## Output
The dashboard displays sales metrics, interactive charts, regional filters, and sales data.
